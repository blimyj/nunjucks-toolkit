Nunjucks 3.2 · render.js toolkit

Fill templates with data, and remember things between runs

This page explains a small toolkit built on Nunjucks, Mozilla's templating language. You write a template, keep its values in a JSON file, and render.js turns the two into a finished letter, invoice or JSON file. Helper functions add numbering, rotating lists, dates and JSON building. Start with how it works, or jump to the helper reference.

{{ expression }}Prints a value. Variables, math, filters, function calls.
{% tag %}Runs logic: if, for, set, macro, include.
{# comment #}A comment. It never reaches the output.

Overview

How it works

You write a template. A small script, render.js, fills it in with your values and prints the result: a letter, an invoice, a JSON file, anything made of text. Each template has two JSON files next to it, and the script also loads extra functions from helpers.js.

invoice.data.jsonYour values: names, prices, lists. You edit it.
invoice.state.jsonWhat earlier runs remembered: counters, positions, the last run time. The script edits it.
invoice.njkThe template: your text with {{ }} where values go. You edit it.
→
node render.js invoice.njkReads all three, runs the template with the helper functions, prints the result, then saves the state file.
→
OutputPrinted to the screen, or saved to a file you name.

Words used on this page

Template
A .njk file in the templates folder. Plain text plus Nunjucks tags.
Data file
name.data.json. The values the template prints. Its top-level keys become variables: "client" becomes {{ client }}.
State file
name.state.json. Values carried from one run to the next. You rarely open it.
Run
One node render.js invoice.njk. Values that change between runs, like counters, change once per run.
Helper
An extra function or filter this toolkit adds to Nunjucks, such as counter() or | date. Every helper is listed in the reference.
Function or filter
A function is called with brackets: counter("invoice"). A filter goes after a value and a pipe: price | pad(4).
Shared file
Another template or .json file whose JSON you pull into this one with jsonFromFile(). It uses the calling template's data, so it needs no data file of its own.

Quick start

From an empty folder to your second run

  1. Set up the folder. Install Nunjucks, then save render.js and helpers.js from the bottom of this page into the folder.

    mkdir my-project && cd my-project
npm install nunjucks
mkdir templates

  2. Write a template. Save it as templates/invoice.njk. | dump writes a value as JSON: text gets its quotes, lists stay lists.

    {
  "invoice": "INV-{{ counter("invoice") | pad(4) }}",
  "bill_to": {{ client.name | dump }},
  "items": {{ items | dump }},
  "total": {{ items | sum("price") }}
}

  3. Create its data and state files. init reads the template and writes a data file with every value it uses, left blank for you.

    node render.js init invoice.njk
    {
  "client": { "name": "" },
  "items": []
}

  4. Fill in the data file, templates/invoice.data.json.

    {
  "client": { "name": "Ada Lovelace" },
  "items": [ { "name": "Notebook", "price": 4.5 }, { "name": "Pen", "price": 1.25 } ]
}

  5. Run it. The first run prints this:

    node render.js invoice.njk
    {
  "invoice": "INV-0001",
  "bill_to": "Ada Lovelace",
  "items": [{"name":"Notebook","price":4.5},{"name":"Pen","price":1.25}],
  "total": 5.75
}

    Run it again and the invoice becomes "INV-0002", because counter() saved the number in invoice.state.json. Add a file name to save the output instead of printing it.

    node render.js invoice.njk out/invoice.json

To try all of this without installing anything, use the workspace. It runs the same render.js in your browser.

Helper reference

Remember between runs

These helpers keep their values in the template's state file. Each one gives one value per run: use it as often as you like inside a template and it prints the same thing everywhere. The next run gets the next value. Every helper takes a key, the name the value is saved under, so different counters and lists never mix.

counter(key, step)

A number that goes up each run.

key
The name it is saved under, such as "invoice".
step
Optional. How much to add each run. Default 1.

The state file starts at 41, so the first run gives 42. | pad(4) adds zeros in front.

rotate(key, list) and upcoming(key, list)

rotate gives the next item of a list each run, and starts over after the last one. upcoming tells you which item the next run will get.

key
The name the position is saved under.
list
An array or a Set. A Set drops duplicates first.
false
Optional third argument to rotate. Stop with an error when every item has been used, instead of starting over.

firstTime(key, value)

True on the first run that sees this value, false on every run after. Use it as a value, in a one-line if, or in {% if %}.

key
The name of the list of seen values.
value
What to check, such as a client ID or a name.

previous(key, fallback) and lastRun

previous gives a saved value as it was before this run. lastRun is a variable every template gets: the time of its last successful run, or blank on the first run.

key
The saved value to read, such as a counter's key.
fallback
Optional. What to give when nothing has been saved yet.

reset(key, value)

Sets a saved value for the next run. Use it to start a counter or rotation over. It prints nothing.

key
The value to change.
value
Optional. What to set it to. Default 0, which makes a counter start at 1 again and a rotation start at the first item.

remember(key, value)

Saves any value for the next run, where previous(key) reads it back. It prints nothing.

key
The name to save it under.
value
Text, a number, a date, a list or a Set. Dates are saved as text and Sets as lists.

--hold, --only, --reverse, --dry-run

Command-line flags that choose which keys move on this run. A held key gives last run's value again and is not saved, so the next normal run carries on from where it was. A reversed key steps back one run.

--hold keys
These keys repeat last run's value; everything else moves on.
--only keys
Only these keys move on; everything else repeats.
--reverse keys
These keys step back one run. A counter counts down by its step; rotate() gives the item before last run's, and before the first item comes the last; firstTime() forgets the value, so the next run sees it as new.
--dry-run
Shows what the next run would print. Nothing is saved, not even an output file.

A key is the name you gave counter(), rotate(), firstTime(), reset() or remember(). Separate several with commas. --hold lastRun keeps the last run time as well. reset() and remember() do nothing when their key is held or reversed, and a key cannot be both held and reversed.

node render.js daily.njk --hold topic        # same topic as last time; day still counts up
node render.js daily.njk --only day          # only day moves on
node render.js daily.njk --hold topic,day    # hold several keys
node render.js daily.njk --reverse topic     # back to the previous topic
node render.js daily.njk --dry-run           # preview the next run

With any of these flags, render.js also prints what happened to each key, such as day: 3 -> 4 and topic: held at 3. A key that no helper uses is reported, which catches typos. From your own code, pass the same choices as the third argument: render("daily.njk", {}, { hold: ["topic"] }) or { reverse: ["topic"] }.

Helper reference

Dates

  • now() is the current date and time.
  • datetime("2027-01-01") makes a date from text. Use it for dates written in the template, or to compare dates.
  • value | date(format, fallback) writes a date using the letters in the table below. The value can be a date or text like "2026-12-25". The fallback is printed when the value is blank.
  • value | dateAdd(amount, unit) adds minutes, hours, days, weeks, months or years. A negative amount subtracts.
  • daysBetween(a, b) counts calendar days from a to b.

Dates use the computer's time zone. "2026-12-25" means midnight local time, so you always get the day you wrote.

Helper reference

Lists and Sets

  • toSet(list) makes a Set from a list, which removes duplicates. A Set has .size and .has(value), and works in {% for %}.
  • set | array turns a Set back into a list. Nunjucks' sort, join and first filters need a list: on a Set, sort silently gives nothing.
  • list | unique removes duplicates from a list in one step.

Helper reference

Writing JSON

JSON by hand

Write the JSON as text, with {{ }} where values go. Four rules keep it valid:

ValueWrite it asWhy
Text{{ name | dump }}dump adds the quotes and escapes any quotes inside. Do not add quotes of your own.
A list or object{{ items | dump }}Printed on its own, a list comes out as a,b,c. dump writes real JSON.
A number or true/false{{ total }}Prints as it is.
A Set{{ tags | array | dump }}dump cannot read a Set, so turn it into a list first.

Optional keys go inside {% if %}, with the comma at the start: {%- if rush %},. The comma then appears only when the key does. The dashes stop skipped keys leaving blank lines. This needs one key above that is always there, like "order" below.

The customer's name contains quotes; dump escapes them. Set rush to true or remove the email in the data to see keys come and go.

jsonFromFile(file, path, values)

Reads the JSON that another file produces and gives it to you as data. The file can be a .json file or a template that outputs JSON. A template run this way sees the same data as the template calling it. Print what you get with | dump.

file
A file in the templates folder, such as "address.njk" or "boxes.json".
path
Optional. One value inside that JSON: names joined with dots, and [0] for the first item of a list. "street.number", "[1].size". A wrong path gives an error that lists what is there.
values
Optional. Extra values for the other file, as an object: { "item": item }. Needed inside a {% for %} loop: the loop's variable, item here, is not passed on by itself.

Open the other files with the tabs. address.njk is a template that outputs JSON; boxes.json is a plain JSON list.

Optional shortcut: json(value) and when(condition, value, otherwise)

Instead of writing the JSON as text, write it as one object and json() prints it with every comma and quote in place. A key whose when() is false is left out. The rest of this page writes JSON by hand; use whichever you find easier to read.

json(v, 2)
The value as JSON, indented by 2. Use 0 for one line. value | json works too.
when(c, v)
v when c is true; otherwise the key or list item is left out. Only works inside json().
when(c, v, o)
v when c is true; otherwise o.

Recipes

Common tasks

Show one section or another

A macro is a section with a name, defined at the top of the template. It can use all of the template's data. Pick one with Nunjucks' one-line if: {{ clientSection() if a + b == 2 else addressSection() }}. Change a or b in the data.

Optional sections in JSON

Each optional section sits inside {%- if %}, … {%- endif %}, with its comma first. Turn showClient and showAddress on and off in the data.

One shared file for every item in a list

line.njk turns one item into JSON. The loop hands each item over with { "item": item } and prints the result with | dump. {{ "," if not loop.last }} puts a comma after every item except the last.

A daily message that changes each run

Rotation, a greeting for first-timers and the date, together.

Workspace

Your own templates

A place to build real templates with the same render.js. Pick a file on the left to edit it; the output follows as you type, without saving.

  • Create a template by typing a name such as letter.njk.
  • Initialise files creates the template's data and state files, with the data file filled with every value the template uses. It never overwrites anything.
  • Render and save is a real run: counters and rotations move on, and the state file is saved.

Files are kept in this browser. In Chrome or Edge, Open templates folder works on your project's real templates folder instead, saving to disk as you type.

The code

render.js, helpers.js and send.js

A ready-made copy of this project, with these files, a package.json and two example templates, is in the nunjucks-toolkit folder that holds this page. Run npm install there to start. To set one up yourself, save both files in your project folder, next to the templates folder. render.js runs templates and holds the helpers that remember things between runs. helpers.js holds the date, list and JSON helpers. The examples on this page run exactly this code.

node render.js invoice.njk                # print the result
node render.js invoice.njk out.txt        # save the result to a file
node render.js invoice.njk --hold invoice # render without moving the invoice number on
// From your own code
const { render, init } = require('./render');
init('invoice.njk');                          // safe to call every time
const text = render('invoice.njk');

render.js

// render.js
const fs = require('fs');
const path = require('path');
const nunjucks = require('nunjucks');
const { addDateHelpers, addSetHelpers, addJsonHelpers } = require('./helpers');

// Templates live in ./templates. Each template has two companion files beside it:
//   invoice.njk          the template
//   invoice.data.json    your values; you edit this file
//   invoice.state.json   counters and other run-to-run values; render.js writes this file
// `node render.js init invoice.njk` creates both companions.
// `node render.js invoice.njk --hold topic` renders without moving "topic" on, and
// `--reverse topic` steps it back one run (see the CLI at the end).
const TEMPLATES = path.join(__dirname, 'templates');

function companions(templateName) {
  const base = templateName.replace(/\.[^./]+$/, '');
  return {
    template: path.join(TEMPLATES, templateName),
    data: path.join(TEMPLATES, base + '.data.json'),
    state: path.join(TEMPLATES, base + '.state.json')
  };
}

function readJson(file) {
  return JSON.parse(fs.readFileSync(file, 'utf8')); // broken JSON stops the run instead of losing data
}

function writeJson(file, value) {
  const tmp = file + '.tmp';
  fs.writeFileSync(tmp, JSON.stringify(value, null, 2) + '\n');
  fs.renameSync(tmp, file);               // atomic swap, never a half-written file
}

const env = new nunjucks.Environment(
  new nunjucks.FileSystemLoader(TEMPLATES),
  { autoescape: false, throwOnUndefined: true }
);
addDateHelpers(env); // now(), datetime(), | date, | dateAdd, daysBetween()
addSetHelpers(env);  // | array, | unique, toSet()
addJsonHelpers(env); // when(), json(), | json

let state = {};    // the state file; changed during the render, saved after it
let before = {};   // the state file as it was when this run started
let thisRun = {};  // values already handed out during this run
let afterRun = {}; // reset() and remember() changes, applied once the render succeeds
let options = {};  // this run's --hold, --only and --reverse lists
let keysUsed = new Set(); // state keys the template's helpers asked about

// What `key` does on this run: 'move' on, 'hold' still, or 'reverse' one step back.
// --reverse and --hold name keys; --only names the keys that move, so the rest hold.
function mode(key) {
  keysUsed.add(key);
  if ((options.reverse || []).includes(key)) return 'reverse';
  if ((options.hold || []).includes(key)) return 'hold';
  if (options.only && !options.only.includes(key)) return 'hold';
  return 'move';
}

// Every helper gives one value per run, however many times the template uses it.
function once(id, compute) {
  if (!(id in thisRun)) thisRun[id] = compute();
  return thisRun[id];
}

// This run's number. Adds `step` (default 1) once per run.
// When held, it gives last run's number again (the first number, unsaved, if it never ran).
// When reversed, it takes `step` off instead: 42 becomes 41.
//   Invoice {{ counter("invoice") | pad(4) }}
function counter(key, step = 1) {
  return once('counter:' + key, () => {
    const m = mode(key);
    if (m === 'hold') return state[key] ?? step;
    state[key] = (state[key] ?? 0) + (m === 'reverse' ? -step : step);
    return state[key];
  });
}

// This run's item from an array or Set: run 1 gets the first item, run 2 the second.
// After the last item it starts over. Pass false as the third argument to stop with an error instead.
// When held, it gives last run's item again (the first item, unsaved, if it never ran).
// When reversed, it goes back to the item before last run's; before the first comes the last.
//   Today's topic: {{ rotate("topic", topics) }}
function rotate(key, items, wrap = true) {
  return once('rotate:' + key, () => {
    const list = Array.from(items ?? []);
    if (list.length === 0) throw new Error(`rotate("${key}"): the list is empty`);
    const used = state[key] ?? 0; // how far the previous runs got
    const m = mode(key);
    if (m === 'hold') return list[(Math.max(used, 1) - 1) % list.length];
    if (m === 'reverse') {
      if (!wrap && used <= 1) throw new Error(`rotate("${key}"): already at the first item, so it cannot go back`);
      const back = used === 0 ? list.length - 1 : (((used - 2) % list.length) + list.length) % list.length;
      state[key] = back + 1;
      return list[back];
    }
    if (!wrap && used >= list.length) {
      throw new Error(`rotate("${key}"): all ${list.length} items are used up`);
    }
    state[key] = (used % list.length) + 1;
    return list[used % list.length];
  });
}

// The item the next run will get from rotate().
//   Coming up: {{ upcoming("topic", topics) }}
function upcoming(key, items) {
  rotate(key, items); // make sure this run has taken its item
  const list = Array.from(items);
  return list[(state[key] ?? 0) % list.length];
}

// True only on the first run that sees `value` under `key`. Seen values are saved as a list.
// When held, it answers the same way but does not record the value, so the next run asks again.
// When reversed, it forgets the value, so the next run sees it as new again.
//   {% if firstTime("clients", client.id) %}Welcome aboard!{% endif %}
function firstTime(key, value) {
  return once('firstTime:' + key + ':' + JSON.stringify(value), () => {
    const m = mode(key);
    const seen = new Set(state[key] ?? []);
    if (m === 'reverse') {
      const had = seen.delete(value);
      state[key] = Array.from(seen);
      return !had;
    }
    if (seen.has(value)) return false;
    if (m === 'hold') return true;
    seen.add(value);
    state[key] = Array.from(seen);
    return true;
  });
}

// What a key held when this run started, or `fallback` if it was never saved.
//   Last invoice: {{ previous("invoice", "none") }}
function previous(key, fallback = null) {
  return before[key] ?? fallback;
}

// Set a key for the next run; prints nothing. {{ reset("topic") }} starts the rotation over.
// Held or reversed, it does nothing.
function reset(key, value = 0) {
  if (mode(key) === 'move') afterRun[key] = value;
  return '';
}

// Save any value for the next run; read it back with previous(). Sets are saved as arrays.
// Held or reversed, it does nothing.
function remember(key, value) {
  if (mode(key) === 'move') afterRun[key] = value instanceof Set ? Array.from(value) : value;
  return '';
}

// Render another template that outputs JSON, and use the result as data.
//   {{ jsonFromFile("address.njk").city }}
//   {{ jsonFromFile("address.njk", "streetAddress.streetName.streetNumber") }}
//   {{ json({ "ship_to": jsonFromFile("address.njk"), "total": total }) }}
// The other template sees the same data as this one. Loop variables are not passed on by
// Nunjucks, so hand them over in an object, after the path or instead of it:
//   jsonFromFile("line.njk", { "item": item })   jsonFromFile("line.njk", "sku", { "item": item })
const inProgress = []; // templates being turned into JSON right now, to catch circles
function jsonFromFile(templateName, path, extra) {
  if (path !== undefined && path !== null && typeof path !== 'string') { extra = path; path = undefined; }
  extra = extra || {};
  const vars = { ...(this && this.ctx), ...extra };
  const value = once('jsonFromFile:' + templateName + ':' + JSON.stringify(extra), () => {
    if (inProgress.includes(templateName)) {
      throw new Error(`jsonFromFile: ${[...inProgress, templateName].join(' -> ')} goes round in a circle`);
    }
    inProgress.push(templateName);
    try {
      const text = env.render(templateName, vars);
      try {
        return JSON.parse(text);
      } catch (err) {
        throw new Error(`jsonFromFile("${templateName}"): its output is not valid JSON (${err.message})`);
      }
    } finally {
      inProgress.pop();
    }
  });
  return path ? valueAt(value, path, templateName) : value;
}

// Follow a path such as "streetAddress.streetName.streetNumber" or "lines[0].sku" into a value.
function valueAt(value, path, from) {
  const parts = path.replace(/\[(\d+)\]/g, '.$1').split('.').filter(Boolean);
  let current = value;
  const walked = [];
  for (const part of parts) {
    const where = walked.length ? '"' + walked.join('.') + '"' : 'the top level';
    if (current === null || typeof current !== 'object') {
      throw new Error(`jsonFromFile("${from}", "${path}"): ${where} is ${JSON.stringify(current)}, so it has no "${part}"`);
    }
    if (!(part in current)) {
      const has = Object.keys(current).join(', ') || 'nothing';
      throw new Error(`jsonFromFile("${from}", "${path}"): no "${part}" in ${where}. It has: ${has}`);
    }
    current = current[part];
    walked.push(part);
  }
  return current;
}

for (const [name, fn] of Object.entries({ counter, rotate, upcoming, firstTime, previous, reset, remember, jsonFromFile })) {
  env.addGlobal(name, fn);
}

// 42 | pad(4)  ->  "0042"
env.addFilter('pad', (n, width = 4) => String(n).padStart(width, '0'));

// Render a template with its data file, then save its state file.
// `extra` adds values JSON cannot hold, such as a Set or a Map, for this run only.
// `opts` chooses what moves on:
//   { hold: ['topic'] }    everything moves on except "topic", which repeats last run's value
//   { only: ['invoice'] }  only "invoice" moves on; every other key repeats
//   { reverse: ['topic'] } "topic" steps back one run; counters count down
//   { dryRun: true }       show what the next run would print, and save nothing
// `opts.report(lines)` receives a summary of what moved and what was held.
function render(templateName, extra = {}, opts = {}) {
  const files = companions(templateName);
  if (!fs.existsSync(files.data)) {
    throw new Error(`${path.basename(files.data)} is missing. Create it with: node render.js init ${templateName}`);
  }
  const data = readJson(files.data);
  state = fs.existsSync(files.state) ? readJson(files.state) : {};
  before = JSON.parse(JSON.stringify(state));
  thisRun = {};
  afterRun = {};
  const both = (opts.hold || []).filter((k) => (opts.reverse || []).includes(k));
  if (both.length) throw new Error(`${both.join(', ')}: a key cannot be both held and reversed`);
  options = opts;
  keysUsed = new Set();
  inProgress.length = 0;
  inProgress.push(templateName);
  // Every template also gets `lastRun`: when it was last rendered successfully, or null.
  const output = env.render(templateName, { lastRun: state.lastRun ?? null, ...data, ...extra });

  Object.assign(state, afterRun);
  if (!(opts.hold || []).includes('lastRun')) state.lastRun = new Date();
  if (opts.report) opts.report(summary(before, state, opts));
  if (!opts.dryRun) writeJson(files.state, state); // only reached when rendering worked
  return output;
}

// One line per state key: what it was, what it is now, or that it was held.
function summary(was, now, opts) {
  const show = (v) => (v === undefined ? 'nothing' : JSON.stringify(v));
  const lines = [];
  for (const key of keysUsed) {
    const m = mode(key);
    if (m === 'hold') lines.push(`${key}: held at ${show(was[key])}`);
    else if (m === 'reverse') lines.push(`${key}: ${show(was[key])} -> ${show(now[key])} (reversed)`);
    else if (JSON.stringify(was[key]) !== JSON.stringify(now[key])) lines.push(`${key}: ${show(was[key])} -> ${show(now[key])}`);
    else lines.push(`${key}: unchanged`);
  }
  for (const key of [...(opts.hold || []), ...(opts.only || []), ...(opts.reverse || [])]) {
    if (key !== 'lastRun' && !keysUsed.has(key)) lines.push(`${key}: no helper in this template uses this key (typo?)`);
  }
  if (opts.dryRun) lines.push('Dry run: nothing was saved');
  return lines;
}

// Work out which values a template reads from its data, as an empty skeleton.
//   {{ client.name }}                         gives { "client": { "name": "" } }
//   {% for item in items %}{{ item.price }}   gives { "items": [{ "price": "" }] }
// Includes, parent templates and jsonFromFile() templates are read too.
function inferData(templateName) {
  const { nodes, parser } = nunjucks;
  const skip = new Set([...Object.keys(env.globals), 'loop', 'lastRun', 'super', 'caller']);
  const defined = new Set(); // names the template sets itself
  const visited = new Set();
  const shape = {};

  // Record a path like ['items', '[]', 'price']. '[]' means "an item of this list",
  // '{}' means "this is an object". A blank value can grow into a list or object; nothing shrinks.
  const isBlank = (v) => v === undefined || v === '';
  const isObject = (v) => typeof v === 'object' && v !== null && !Array.isArray(v);
  function touch(segments) {
    let node = shape;
    for (let i = 0; i < segments.length; i++) {
      const seg = segments[i];
      const next = segments[i + 1];
      if (seg === '[]') {                                  // node is a list; step into its first item
        if (next === undefined || next === '{}') return;
        if (next === '[]') { if (isBlank(node[0])) node[0] = []; }
        else if (isBlank(node[0])) node[0] = {};
        node = node[0];
        if (typeof node !== 'object' || node === null) return;
        continue;
      }
      if (seg === '{}') return;
      if (next === undefined) { if (!(seg in node)) node[seg] = ''; return; }
      if (next === '[]') { if (isBlank(node[seg])) node[seg] = []; if (!Array.isArray(node[seg])) return; }
      else { if (isBlank(node[seg])) node[seg] = {}; if (!isObject(node[seg])) return; }
      node = node[seg];
    }
  }

  // Filters and helpers that tell us a value is a list (or, for dictsort, an object)
  const LIST_FILTERS = new Set(['join', 'sort', 'first', 'last', 'unique', 'array', 'batch', 'slice',
    'sum', 'groupby', 'select', 'reject', 'selectattr', 'rejectattr', 'random']);
  const LIST_ARGS = { rotate: 1, upcoming: 1, toSet: 0 }; // which argument is the list

  // client.name -> ['client', 'name']; a loop variable resolves to the list item it stands for
  function pathOf(node, scope) {
    if (node instanceof nodes.Symbol) {
      const name = node.value;
      if (name in scope) return scope[name];
      if (skip.has(name) || defined.has(name)) return null;
      return [name];
    }
    if (node instanceof nodes.LookupVal && node.val instanceof nodes.Literal) {
      const base = pathOf(node.target, scope);
      if (!base) return null;
      return [...base, typeof node.val.value === 'number' ? '[]' : String(node.val.value)];
    }
    return null;
  }

  function readTemplate(name, scope) {
    if (visited.has(name)) return;
    visited.add(name);
    let src;
    try { src = fs.readFileSync(path.join(TEMPLATES, name), 'utf8'); } catch (err) { return; }
    walk(parser.parse(src, [], env.opts), scope);
  }

  function walk(node, scope) {
    if (!node || typeof node !== 'object') return;
    if (Array.isArray(node)) { node.forEach((n) => walk(n, scope)); return; }
    if (!(node instanceof nodes.Node)) return;

    if (node instanceof nodes.Symbol || node instanceof nodes.LookupVal) {
      const p = pathOf(node, scope);
      if (p) touch(p);
      else if (node instanceof nodes.LookupVal) { walk(node.target, scope); walk(node.val, scope); }
      return;
    }
    if (node instanceof nodes.For) {
      let source = node.arr;
      while (source instanceof nodes.Filter) { walk(source.args.children.slice(1), scope); source = source.args.children[0]; }
      const listPath = pathOf(source, scope);
      if (!listPath) walk(source, scope);
      const inner = Object.assign(Object.create(null), scope);
      if (node.name instanceof nodes.Array) {         // {% for key, value in object %}
        if (listPath) touch([...listPath, '{}']);
        node.name.children.forEach((s) => { inner[s.value] = null; });
      } else {
        if (listPath) touch([...listPath, '[]']);
        inner[node.name.value] = listPath ? [...listPath, '[]'] : null;
      }
      walk(node.body, inner);
      walk(node.else_, scope);
      return;
    }
    if (node instanceof nodes.Set) {
      walk(node.value, scope);
      walk(node.body, scope);
      node.targets.forEach((t) => defined.add(t.value));
      return;
    }
    if (node instanceof nodes.Macro) {                 // also {% call %} blocks
      const inner = Object.assign(Object.create(null), scope);
      node.args.children.forEach((arg) => {
        if (arg instanceof nodes.Symbol) inner[arg.value] = null;
        else if (arg instanceof nodes.KeywordArgs) {
          arg.children.forEach((pair) => { inner[pair.key.value] = null; walk(pair.value, scope); });
        }
      });
      if (node.name instanceof nodes.Symbol) defined.add(node.name.value);
      walk(node.body, inner);
      return;
    }
    if (node instanceof nodes.Filter) {
      const target = node.args.children[0];
      const p = target && pathOf(target, scope);
      if (p && LIST_FILTERS.has(node.name.value)) touch([...p, '[]']);
      else if (p && node.name.value === 'dictsort') touch([...p, '{}']);
      walk(node.args, scope);
      return;
    }
    if (node instanceof nodes.FunCall) {
      if (node.name instanceof nodes.LookupVal) {     // a method call such as name.trim()
        const p = pathOf(node.name.target, scope);
        if (p) touch(p); else walk(node.name.target, scope);
      } else if (node.name instanceof nodes.Symbol && node.name.value in LIST_ARGS) {
        const arg = node.args.children[LIST_ARGS[node.name.value]];
        const p = arg && pathOf(arg, scope);
        if (p) touch([...p, '[]']);
      } else if (node.name instanceof nodes.Symbol && node.name.value === 'jsonFromFile') {
        // jsonFromFile("x.njk") reads this template's data too. Names passed in the extra-values
        // object, such as { "item": item }, come from the caller rather than the data file.
        const target = node.args.children[0];
        const passed = node.args.children.find((a) => a instanceof nodes.Dict && !(a instanceof nodes.KeywordArgs));
        const inner = Object.assign(Object.create(null), scope);
        if (passed) {
          passed.children.forEach((pair) => {
            const key = pair.key instanceof nodes.Literal || pair.key instanceof nodes.Symbol ? String(pair.key.value) : null;
            if (key) inner[key] = pathOf(pair.value, scope);
          });
        }
        if (target instanceof nodes.Literal) readTemplate(target.value, inner);
      }
      walk(node.args, scope);
      return;
    }
    if (node instanceof nodes.Is) {                    // x is divisibleby(3): skip the test name
      walk(node.left, scope);
      if (node.right instanceof nodes.FunCall) walk(node.right.args, scope);
      return;
    }
    if (node instanceof nodes.Pair) { walk(node.value, scope); return; }
    if (node instanceof nodes.Include || node instanceof nodes.Extends) {
      if (node.template instanceof nodes.Literal) readTemplate(node.template.value, scope);
      else walk(node.template, scope);
      return;
    }
    if (node instanceof nodes.Import) { defined.add(node.target.value); return; }
    if (node instanceof nodes.FromImport) {
      node.names.children.forEach((n) => defined.add(n instanceof nodes.Pair ? n.value.value : n.value));
      return;
    }
    if (node instanceof nodes.Block) { walk(node.body, scope); return; }
    node.iterFields((value) => walk(value, scope));
  }

  readTemplate(templateName, Object.create(null));
  return shape;
}

// Create a template's data and state files. Existing files are never replaced:
// a data file that already exists only gets the keys it is missing.
function init(templateName) {
  const files = companions(templateName);
  if (!fs.existsSync(files.template)) throw new Error(`Template not found: ${templateName}`);
  const skeleton = inferData(templateName);
  const report = { data: path.basename(files.data), state: path.basename(files.state), createdData: false, createdState: false, addedKeys: [] };

  if (!fs.existsSync(files.data)) {
    writeJson(files.data, skeleton);
    report.createdData = true;
    report.addedKeys = Object.keys(skeleton);
  } else {
    const data = readJson(files.data);
    for (const key of Object.keys(skeleton)) {
      if (!(key in data)) { data[key] = skeleton[key]; report.addedKeys.push(key); }
    }
    if (report.addedKeys.length) writeJson(files.data, data);
  }
  if (!fs.existsSync(files.state)) {
    writeJson(files.state, {});
    report.createdState = true;
  }
  return report;
}

function describe(r) {
  const keys = r.addedKeys.length ? r.addedKeys.join(', ') : 'none';
  return [
    r.createdData ? `Created ${r.data} with keys: ${keys}` : (r.addedKeys.length ? `Added to ${r.data}: ${keys}` : `${r.data} already has every key`),
    r.createdState ? `Created ${r.state}` : `${r.state} already exists`
  ].join('\n');
}

// Split the command line into names and options. Keys can be repeated or comma-separated:
//   --hold topic --hold invoice    --hold topic,invoice    --hold=topic,invoice
function parseArgs(argv) {
  const opts = { hold: [], reverse: [], only: null, dryRun: false };
  const names = [];
  for (let i = 0; i < argv.length; i++) {
    let [flag, value] = argv[i].startsWith('--') ? argv[i].split(/=(.*)/s) : [argv[i]];
    if (flag === '--dry-run') opts.dryRun = true;
    else if (flag === '--hold' || flag === '--only' || flag === '--reverse') {
      if (value === undefined) value = argv[++i];
      if (!value || value.startsWith('--')) throw new Error(`${flag} needs one or more keys, such as ${flag} invoice,topic`);
      const keys = value.split(',').map((k) => k.trim()).filter(Boolean);
      if (flag === '--hold') opts.hold.push(...keys);
      else if (flag === '--reverse') opts.reverse.push(...keys);
      else opts.only = [...(opts.only || []), ...keys];
    } else if (flag.startsWith('--')) throw new Error(`Unknown option ${flag}`);
    else names.push(flag);
  }
  return { names, opts };
}

const USAGE = `Usage:

  node render.js <template.njk> [output file]         render, then save the state file

Options for rendering:

  --only <keys>      only these keys move on; everything else repeats

  --dry-run          print what the next run would give; save nothing
Keys are the names given to counter(), rotate(), firstTime(), reset() and remember().
Separate several with commas: --hold invoice,topic. --hold lastRun keeps lastRun too.`;

module.exports = { render, init, inferData, describe, parseArgs };

if (require.main === module) {

// helpers.js: date, list and JSON helpers for Nunjucks
const MONTHS = ['January', 'February', 'March', 'April', 'May', 'June', 'July',
  'August', 'September', 'October', 'November', 'December'];
const DAYS = ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'];

// Turn a Date, a timestamp or a string into a Date.
// "2026-12-25" means local midnight here (plain JavaScript would read it as UTC midnight).
function toDate(value) {
  if (value instanceof Date) return new Date(value.getTime());
  if (value == null || value === '') throw new Error('Expected a date, got ' + JSON.stringify(value));
  if (typeof value === 'string') {
    const day = value.match(/^(\d{4})-(\d{2})-(\d{2})$/);
    if (day) return new Date(+day[1], +day[2] - 1, +day[3]);
    value = value.replace(/^(\d{4}-\d{2}-\d{2}) (\d)/, '$1T$2'); // accept "2026-12-25 18:30"
  }
  const d = new Date(value);
  if (isNaN(d.getTime())) throw new Error('Not a valid date: ' + JSON.stringify(value));
  return d;
}

// Tokens: YYYY YY MMMM MMM MM M DD D dddd ddd HH H hh h mm ss A
// Put literal words in [brackets]: "D MMM [at] HH:mm"
// A blank value ("" or null), common in a freshly initialised data file, prints the fallback,
// or nothing: {{ lastRun | date("D MMM", "never") }}. An undefined variable is still an error.
function formatDate(value, format = 'YYYY-MM-DD', fallback = '') {
  if (value === null || value === '') return fallback;
  const d = toDate(value);
  const pad = (n) => String(n).padStart(2, '0');
  const hours12 = d.getHours() % 12 || 12;
  const parts = {
    YYYY: d.getFullYear(), YY: pad(d.getFullYear() % 100),
    MMMM: MONTHS[d.getMonth()], MMM: MONTHS[d.getMonth()].slice(0, 3),
    MM: pad(d.getMonth() + 1), M: d.getMonth() + 1,
    DD: pad(d.getDate()), D: d.getDate(),
    dddd: DAYS[d.getDay()], ddd: DAYS[d.getDay()].slice(0, 3),
    HH: pad(d.getHours()), H: d.getHours(), hh: pad(hours12), h: hours12,
    mm: pad(d.getMinutes()), ss: pad(d.getSeconds()), A: d.getHours() < 12 ? 'AM' : 'PM'
  };
  return format.replace(/\[([^\]]*)\]|YYYY|YY|MMMM|MMM|MM|M|DD|D|dddd|ddd|HH|H|hh|h|mm|ss|A/g,
    (token, literal) => (literal !== undefined ? literal : parts[token]));
}

// Add minutes, hours, days, weeks, months or years. A negative amount subtracts.
function dateAdd(value, amount, unit = 'days') {
  const d = toDate(value);
  const n = Number(amount);
  const u = String(unit).replace(/s$/, '');
  switch (u) {
    case 'minute': d.setMinutes(d.getMinutes() + n); break;
    case 'hour': d.setHours(d.getHours() + n); break;
    case 'day': d.setDate(d.getDate() + n); break;
    case 'week': d.setDate(d.getDate() + 7 * n); break;
    case 'month':
    case 'year': {
      const day = d.getDate();
      d.setDate(1);
      if (u === 'month') d.setMonth(d.getMonth() + n);
      else d.setFullYear(d.getFullYear() + n);
      const lastDay = new Date(d.getFullYear(), d.getMonth() + 1, 0).getDate();
      d.setDate(Math.min(day, lastDay)); // Jan 31 + 1 month = Feb 28, not Mar 3
      break;
    }
    default: throw new Error('Unknown unit "' + unit + '". Use minutes, hours, days, weeks, months or years.');
  }
  return d;
}

// Whole calendar days from a to b. Negative when b is earlier.
function daysBetween(a, b) {
  const start = toDate(a);
  const end = toDate(b);
  start.setHours(0, 0, 0, 0);
  end.setHours(0, 0, 0, 0);
  return Math.round((end - start) / 86400000);
}

function addDateHelpers(env) {
  env.addGlobal('now', () => new Date());
  env.addGlobal('datetime', toDate);
  env.addGlobal('daysBetween', daysBetween);
  env.addFilter('date', formatDate);
  env.addFilter('dateAdd', dateAdd);
}

// Nunjucks loops over Sets and Maps on its own, but sort, join, list and "in" do not
// understand them. These fill the gaps.
function addSetHelpers(env) {
  env.addFilter('array', (value) => Array.from(value)); // Set to array; Map to [key, value] pairs
  env.addFilter('unique', (value) => Array.from(new Set(value)));
  env.addGlobal('toSet', (value) => new Set(value || []));
}

// Inline conditions and JSON output.
// A false when() with no `otherwise` gives SKIP: it prints as nothing, and json() leaves it out.
const SKIP = Object.freeze({ toString: () => '' });

// when(condition, value)              value, or nothing
// when(condition, value, otherwise)   value or otherwise
function when(condition, value, otherwise = SKIP) {
  return condition ? value : otherwise;
}

// Remove SKIP keys and list items; turn Sets, Maps and macro output into plain JSON values.
function withoutSkipped(value) {
  if (value === SKIP) return undefined;
  if (value instanceof String) return String(value); // macro output
  if (value instanceof Set) return withoutSkipped(Array.from(value));
  if (value instanceof Map) return withoutSkipped(Object.fromEntries(value));
  if (Array.isArray(value)) return value.filter((v) => v !== SKIP).map(withoutSkipped);
  if (value && typeof value === 'object' && Object.getPrototypeOf(value) === Object.prototype) {
    const out = {};
    for (const [key, v] of Object.entries(value)) if (v !== SKIP) out[key] = withoutSkipped(v);
    return out;
  }
  return value;
}

// json(value, indent) and value | json print valid JSON. Keys and list items from a false when()
// are left out, so there are no commas to manage.
function addJsonHelpers(env) {
  const safe = env.getFilter('safe'); // keeps HTML escaping away from the quotes
  const json = (value, indent = 2) => safe(JSON.stringify(withoutSkipped(value), null, indent));
  env.addGlobal('when', when);
  env.addGlobal('json', json);
  env.addFilter('json', json);
}

module.exports = { addDateHelpers, addSetHelpers, addJsonHelpers, toDate, formatDate, dateAdd, daysBetween, when };

send.js

Optional. send.js renders a template and sends the result to a URL, using the fetch built into Node 18 and later. It needs nothing else installed.

  1. It keeps a copy of the template's state file.
  2. It renders the template, which moves counters on as usual.
  3. It sends the result as the request body and waits for a 2xx reply, giving up after 30 seconds.
  4. It keeps a copy of every payload in sent/, named by the local time it was sent, such as invoice.2026-10-27T21-55-38.json. A failed send ends in .failed.json.
  5. If the request failed, it puts the state file back as it was, so the next try sends the same invoice number.

Set where requests go at the top of send.js. Each template you send needs a path in PATHS, which is added to the base URL.

const BASE_URL = process.env.BASE_URL || 'http://localhost:3000';
const METHOD = process.env.METHOD || 'POST';
const HEADERS = { 'Content-Type': 'application/json' };

const PATHS = {
  'invoice.njk': '/invoices'
};
node send.js invoice.njk                                    # POST to http://localhost:3000/invoices
METHOD=PUT BASE_URL=https://api.example.com node send.js invoice.njk   # for one run
node send.js invoice.njk --hold invoice                     # the same flags as render.js
node send.js invoice.njk --dry-run                          # send the next payload, save no state

With METHOD=GET or METHOD=HEAD it just makes the request: the template is not rendered, so no state changes and no copy is kept.

The server's reply is printed, followed by a line such as Sent at 2026-10-27T22:10:27: 201 Created. From your own code, await send("invoice.njk") returns the reply, and throws if the request failed.

// send.js: render a template, then send the result to a URL with fetch (built into Node 18+).
// The state file only keeps this run if the request succeeds (a 2xx reply); otherwise it is put
// back as it was, so a failed send does not use up an invoice number or a rotation step.
// A copy of every payload is kept, named by the local time it was sent:
// sent/<name>.<time>.json, or <name>.<time>.failed.json when the request failed.
//
//   node send.js invoice.njk                       sends to BASE_URL + PATHS["invoice.njk"]
//   node send.js invoice.njk --hold invoice        render.js flags work too
//   node send.js invoice.njk --dry-run             send the next payload without saving anything
//   METHOD=PUT BASE_URL=https://api.example.com node send.js invoice.njk
const fs = require('fs');
const path = require('path');
const { render, parseArgs } = require('./render');

// Where requests go. BASE_URL and METHOD in the environment override these for one run.
const BASE_URL = process.env.BASE_URL || 'http://localhost:3000';
const METHOD = process.env.METHOD || 'POST';
const HEADERS = { 'Content-Type': 'application/json' };
const TIMEOUT_MS = 30000; // give up on a server that does not answer

// The path each template is sent to, added to BASE_URL.
const PATHS = {
  'invoice.njk': '/invoices'
};

const TEMPLATES = path.join(__dirname, 'templates');
const SENT = path.join(__dirname, 'sent');

// This computer's local time, such as 2026-10-27T21:53:08
function localTime(d = new Date()) {
  const pad = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}` +
    `T${pad(d.getHours())}:${pad(d.getMinutes())}:${pad(d.getSeconds())}`;
}

// Render `templateName` and send it as the request body.
// `opts` takes the same choices as render(): { hold, only, reverse, dryRun, report }.
// `to` can change where it goes for this call: { baseUrl, method, headers }.
// GET and HEAD carry no body, so they skip the template: nothing is rendered, saved or kept.
// Returns { sentAt, copy, reply }: the send time, where the payload copy was kept (null for
// GET and HEAD), and the server's reply as { status, statusText, text }. Throws if the request fails.
async function send(templateName, opts = {}, { baseUrl = BASE_URL, method = METHOD, headers = HEADERS } = {}) {
  if (!(templateName in PATHS)) throw new Error(`No path for ${templateName}: add it to PATHS in send.js`);
  method = method.toUpperCase();
  if (!/^[A-Z]+$/.test(method)) throw new Error(`Not a request method: ${method}`);
  const url = baseUrl.replace(/\/+$/, '') + PATHS[templateName];
  const name = templateName.replace(/\.[^./]+$/, '');
  const state = path.join(TEMPLATES, name + '.state.json');

  const hasBody = method !== 'GET' && method !== 'HEAD';
  const saved = fs.existsSync(state) ? fs.readFileSync(state, 'utf8') : null; // the state file before this run
  const body = hasBody ? render(templateName, {}, opts) : undefined;
  const sentAt = localTime();

  let reply = null;
  let problem = null;
  try {
    const res = await fetch(url, { method, headers, body, signal: AbortSignal.timeout(TIMEOUT_MS) });
    reply = { status: res.status, statusText: res.statusText, text: await res.text() };
    if (!res.ok) problem = `the server replied ${res.status} ${res.statusText}`;
  } catch (err) {
    if (err.name === 'TimeoutError') problem = `no reply after ${TIMEOUT_MS / 1000} seconds`;
    else if (err.cause) problem = `could not reach the server (${err.cause.code || err.cause.message})`;
    else problem = err.message;
  }

  if (!hasBody) {
    if (problem) {
      const err = new Error(`${method} ${url} at ${sentAt} failed: ${problem}.`);
      err.reply = reply;
      throw err;
    }
    return { sentAt, copy: null, reply };
  }

  // Colons are not allowed in file names on every system, so 21:53:08 becomes 21-53-08
  fs.mkdirSync(SENT, { recursive: true });
  const stem = path.join(SENT, `${name}.${sentAt.replace(/:/g, '-')}`);
  const end = problem ? '.failed.json' : '.json';
  let copy = stem + end;
  for (let n = 2; fs.existsSync(copy); n++) copy = `${stem}-${n}${end}`; // two sends in the same second
  fs.writeFileSync(copy, body);

  if (problem) {
    if (saved === null) fs.rmSync(state, { force: true });
    else fs.writeFileSync(state, saved);
    const err = new Error(`${method} ${url} at ${sentAt} failed: ${problem}.\n` +
      `templates/${name}.state.json is back to how it was before this run. ` +
      `Payload kept in ${path.relative(__dirname, copy)}`);
    err.reply = reply;
    throw err;
  }
  return { sentAt, copy, reply };
}

module.exports = { send };

if (require.main === module) {
  (async () => {
    try {
      const { names, opts } = parseArgs(process.argv.slice(2));
      if (!names[0]) {
        console.log('Usage: node send.js <template.njk> [--hold keys] [--only keys] [--reverse keys] [--dry-run]');
        return;
      }
      if (opts.hold.length || opts.reverse.length || opts.only || opts.dryRun) {
        opts.report = (lines) => console.error(lines.join('\n'));
      }
      const { sentAt, copy, reply } = await send(names[0], opts);
      if (reply.text) console.log(reply.text); // the server's reply body
      console.error(`Sent at ${sentAt}: ${reply.status} ${reply.statusText}.` +
        (copy ? ` Payload kept in ${path.relative(__dirname, copy)}` : ''));
    } catch (err) {
      console.error(err.message);
      if (err.reply && err.reply.text) console.error('The server said: ' + err.reply.text);
      process.exitCode = 1;
    }
  })();
}

Language basics

Nunjucks itself

The lessons below teach the Nunjucks language: printing values, filters, conditions, loops, macros and template inheritance. Each has live examples and some have challenges. Nothing in them depends on the helpers above.

Basics 1

Setup

Install the package from npm. One dependency, no build step.

npm install nunjucks

Point Nunjucks at a folder of templates, then render a file from that folder with a data object (the "context"). Autoescaping of HTML is on by default when you call configure.

const nunjucks = require('nunjucks');

// Templates live in ./views. Autoescape is on by default.
nunjucks.configure('views', { autoescape: true });

// Render views/hello.njk with some data
const html = nunjucks.render('hello.njk', { name: 'Ada' });

// Or render a string directly, no files involved
nunjucks.renderString('Hello {{ name }}', { name: 'Ada' }); // "Hello Ada"

Templates are plain text files. Any extension works; .njk is the convention (Eleventy uses it), and .html is common too.

{# views/hello.njk #}
<h1>Hello, {{ name }}!</h1>

In the browser, load the full build from a CDN and call renderString. The full build includes the compiler. The "slim" build is smaller and only runs templates you precompiled ahead of time (see lesson 10).

<script src="https://cdnjs.cloudflare.com/ajax/libs/nunjucks/3.2.4/nunjucks.min.js"></script>
<script>
  document.body.innerHTML = nunjucks.renderString('<p>Hi {{ name }}</p>', { name: 'Ada' });
</script>

Basics 2

Delimiters and variables

Double braces print a value. Use dot or bracket notation to reach into objects and arrays, exactly like JavaScript. A missing value prints as an empty string rather than crashing, which is convenient and also a classic source of silent bugs.

Expressions support the usual math (+ - * / // % **), string joining with ~, and calling functions or methods on values. Edit anything below.

Basics 3

Filters

A filter transforms a value. Write it after a pipe: {{ name | upper }}. Filters take arguments in parentheses and chain left to right. A {% filter %} block applies one filter to everything inside it.

Gotcha

default only replaces undefined values. To also replace empty strings, zero and false, pass true as the second argument: {{ title | default("Untitled", true) }}.

Basics 4

Conditions and tests

if, elif and else work as you expect. Comparisons use JavaScript operators (==, ===, !=, <, >= and so on), and logic uses the words and, or and not. in checks membership in an array or string.

There is also an inline form, {{ "a" if cond else "b" }}, and a set of tests written with is, such as is defined or is divisibleby(3).

Basics 5

Loops

for iterates arrays, objects (as key, value) and strings. Inside the loop a loop object tells you where you are. An else branch runs when there was nothing to iterate. Filters apply to the collection too, so sorting happens right in the loop header.

Three globals help with loops: range(start, stop, step), cycler(...values) for alternating classes, and joiner(sep), which prints its separator on every call except the first.

Basics 6

Variables and whitespace

{% set %} creates or updates a variable. The block form, {% set x %}...{% endset %}, captures everything rendered inside it, which is handy for building up a chunk of markup and reusing it.

Scope has one rule worth memorising: a variable first created inside a for loop (or a macro) stays there. If the variable already exists outside the loop, the loop updates it. So declare counters before the loop.

You probably noticed the blank lines the earlier loops left behind. Each tag sits on its own line, and that line's newline survives. A dash on either side of a tag, {%- or -%}, eats all whitespace on that side. It works on {{- too. Turn on Show whitespace in the output pane to see exactly what happens.

Tip

For whole projects, set trimBlocks: true and lstripBlocks: true in configure. Together they remove the newline after each tag and the indentation before it, so you rarely need dashes at all.

Basics 7

Template inheritance

This is the feature that makes Nunjucks worth it. A base template defines the page skeleton and marks regions with {% block name %}. A child template declares {% extends "base.njk" %} and overrides only the blocks it cares about. Inside an override, {{ super() }} inserts the parent's version of that block.

Anything in a child template outside a block is ignored. The template name in extends can be a variable, so a page can pick its layout from data. Switch to the Preview tab to see the rendered HTML.

Basics 8

Includes and macros

{% include "file.njk" %} renders another template in place, with access to the current context, including loop variables. Add ignore missing to skip silently when the file does not exist.

A macro is a reusable function that returns markup. It takes positional and keyword arguments with defaults. Put macros in their own file and bring them in with {% import "forms.njk" as forms %} or {% from "forms.njk" import input %}. Imported macros do not see your page's variables unless you add with context.

{% call %} passes a block of content into a macro, where {{ caller() }} renders it. That is how you build wrappers like fieldsets, cards and modals.

Basics 9

Escaping and safety

With autoescape on, every {{ }} output has < > & " ' converted to HTML entities. That is what stops a user-supplied comment from injecting a script. When you have markup you trust, mark it with | safe. Output from macros and from {% set %} blocks is already marked safe.

Unlike Jinja, Nunjucks has no tag for switching escaping off in one region. Autoescape is an environment setting, so generating plain text means autoescape: false in configure. {% raw %}...{% endraw %} prints template syntax literally, which you need when the page itself documents Nunjucks (this page uses it a lot) or when another framework shares the curly braces.

Gotcha

Only strings get escaped. Numbers and booleans pass straight through, and a value that was marked safe stays safe through most filters. If a custom filter returns HTML, wrap the result in new nunjucks.runtime.SafeString(html) so callers do not need to add | safe.

Basics 10

Node, Express and custom filters

configure returns an Environment. The environment is where you register your own filters and globals, and you can create several environments if different parts of an app need different settings.

const nunjucks = require('nunjucks');
const env = nunjucks.configure('views', { autoescape: true, trimBlocks: true, lstripBlocks: true });

// A filter is a plain function: the piped value comes first, arguments follow
env.addFilter('shout', (str) => `${str}!`);
env.addFilter('money', (n, currency = 'USD') =>
  new Intl.NumberFormat('en-US', { style: 'currency', currency }).format(n));

// Globals are available in every template
env.addGlobal('now', () => new Date());

// Async filters take a callback and are flagged with `true`
env.addFilter('fetchTitle', (url, done) => {
  getTitle(url).then((title) => done(null, title), done);
}, true);

The editor below has shout, money and now already registered, so you can try them.

Express

Pass the app to configure and Nunjucks installs itself as the view engine. Then res.render works as usual.

const express = require('express');
const nunjucks = require('nunjucks');

const app = express();
nunjucks.configure('views', { autoescape: true, express: app, watch: true });
app.set('view engine', 'njk');

app.get('/', (req, res) => {
  res.render('index', { name: 'Ada', items: ['one', 'two'] }); // renders views/index.njk
});

app.listen(3000);

Precompiling for the browser

Shipping the compiler to browsers is wasteful. Precompile your templates to a JavaScript file, load it with the slim build, and render by name as usual.

npx nunjucks-precompile views > public/templates.js
<script src="https://cdnjs.cloudflare.com/ajax/libs/nunjucks/3.2.4/nunjucks-slim.min.js"></script>
<script src="/templates.js"></script>
<script>
  // Precompiled templates are picked up automatically
  document.body.innerHTML = nunjucks.render('hello.njk', { name: 'Ada' });
</script>

Eleventy

Eleventy treats .njk files as Nunjucks out of the box. Add filters through its config instead of a Nunjucks environment: eleventyConfig.addFilter("money", fn). Everything else on this page applies unchanged, including layouts, which Eleventy wires up through front matter rather than extends.

Things that trip people up

  • It is not Python. There is no len() or .items(). Use filters (| length) or JavaScript methods, which you can call directly: {{ name.trim() }}.
  • Undefined is silent. A typo in a variable name prints nothing. Turn on throwOnUndefined while developing.
  • == is loose. It is JavaScript's double equals. Use === when types matter.
  • Loop scope. Declare a variable before a loop if you want to update it inside the loop and read it afterwards.
  • Paths. Template names in extends, include and import resolve from the configured search path, not from the current file, unless they start with ./ or ../.
  • Imported macros and context. They cannot see your page variables unless you import with context, or pass values as arguments (the cleaner option).
  • Blank lines everywhere. Use trimBlocks and lstripBlocks, or dashes.
